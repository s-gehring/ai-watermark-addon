# Security policy

The add-on runs on every page you visit and fetches images from them, so security issues matter. Examples are ways for a web page to execute code in the add-on, to read data from other sites through it, or to make it send requests it should not send.

Please report vulnerabilities privately via [GitHub's private vulnerability reporting](https://github.com/s-gehring/ai-watermark-addon/security/advisories/new), not as a public issue. You will get an answer within a week.

Only the latest version on the `main` branch is supported.

Detection errors (false positives, missed AI images) are not security issues; please report them as regular [issues](https://github.com/s-gehring/ai-watermark-addon/issues).
